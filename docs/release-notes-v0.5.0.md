# md2rednote v0.5.0

This release fixes Markdown image rendering in the local app.

## Changes

- Local Markdown images now render correctly in preview and PNG export.
- Added an image base directory field for relative image paths like `images/demo.png`.
- Improved Markdown image parsing for optional image titles.
